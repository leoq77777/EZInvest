## 工作流程

### 端到端处理流程

1. **查询扩展和标的识别**
   - 使用LLM扩展用户查询
   - 识别股票代码或名称
   - 提取关注点

2. **数据获取**
   - 获取股票基本信息
   - 检查并获取历史数据
   - 确保数据可用性

3. **量化分析**
   - 计算技术指标
   - 生成量化分析报告

4. **政策新闻分析**
   - 搜索相关新闻和政策
   - 生成新闻分析摘要

5. **数据摘要**
   - 获取实时数据
   - 生成数据趋势摘要

6. **综合建议生成**
   - 整合所有分析结果
   - 使用LLM生成投资建议
   - 输出最终报告

## API接口

### POST /api/query
同步处理查询请求

**请求体:**
```json
{
  "query": "最近的apple股票还能买吗",
  "stream": false
}
```

**响应:**
```json
{
  "success": true,
  "query": "最近的apple股票还能买吗",
  "symbol": "AAPL",
  "name": "苹果",
  "advice": "...",
  "quant_analysis": "...",
  "news_analysis": "..."
}
```

### POST /api/query/stream
流式处理查询请求（Server-Sent Events）

### GET /api/health
健康检查

## 错误处理

- 标的识别失败：返回友好错误提示
- 数据获取失败：尝试从数据库获取或返回错误
- 工具调用失败：记录日志并继续处理
- API错误：返回HTTP 500错误
